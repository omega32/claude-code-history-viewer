## Decisions

- `profile_paths.rs` wraps all eight native directory functions and process-environment access, isolates the known macOS managed-settings path, and owns thread-local nested guards. The renamed `native_dirs` dependency plus Clippy's resolved-method restrictions prevent accidental old imports; source preflight also rejects grouped environment imports, unreviewed compile-time environment macros, unsupported integration test attributes and weakened/executable first guards.
- The build script recognizes only absent activation (native), `isolated-v1` (custom isolation cfg) and `live-v1` (custom live-test cfg). This is independent of Cargo features and runtime environment. All nine native diagnostics are ignored and require the latter build mode; the supported live command additionally requires an acknowledgement argument. No live diagnostic was run.
- Owned blocking work and the one provider-loading Rayon loop capture explicit profile context and restore prior worker state on return/unwind. Unrelated threads do not inherit it. WSL discovery/resolution refuses before registry, command or UNC access during isolation.
- The runner is strict TypeScript compiled by the existing pinned compiler into ignored `scratch/test-tools`, using the existing Node runtime and its built-in test API without new dependencies or native type stripping. It owns fresh process directories and separate Cargo output, preserves toolchain caches, rejects inherited alternate compiler/runner/alias overrides, and enforces serial libtest. Local Cargo/Rustup configuration remains trusted build input.
- The supported package scripts, just recipes, tracked afc configuration, active architect/review instructions and CI use the runner. Direct test/coverage/mutation Cargo aliases were removed because they bypassed activation. The frontend release agent retains its scope without the obsolete assertion that this host cannot run Cargo. Windows CI is added for both PRs and pushes; its nextest store and JUnit path agree. Coverage retains LCOV for Codecov.
- Version decision: **1.29.0 → 1.29.1**, one compatible patch for the shipped directory/environment dispatch refactor and worker wrappers. `scripts/sync-version.cjs` synchronized Cargo/Tauri mirrors, and Cargo updated its own package lock entry. No dependency versions changed. No release was published or commit created.

## Validation
