# Hermes backup protocol

Add read-only Hermes backup source discovery and isolated offline browsing to the existing headless backup protocol. PowerPoint backup support is deferred.

`--hermes-backup-sources` emits `schemaVersion:1`, `kind:"hermes-backup-sources"`, `provider:"hermes"`, and `sources:[{id,root,databasePath,relativePath}]`. Discovery reuses the selected Hermes home and native profile layout without opening databases, launching Hermes, reading credentials/configuration, or hiding inspection errors. IDs are `default` or `profile-<lowercase SHA-256 of the UTF-8 profile name>`; payload paths are `default/state.db` or `profiles/<canonical percent-encoded profile name>/state.db`. Symlink/reparse paths, unsupported store types and aliases are rejected.

`--list-backup-sessions <absolute-payload-root> --provider hermes` and `--dump-backup-session <payload-relative-database> --backup-root <absolute-payload-root> --provider hermes --backup-session-id <native-id>` read only standalone databases in that strict layout. Each database must pass SQLite quick integrity and required-schema checks; sidecars, unknown files and symlink/reparse components are rejected. Offline loading reuses Hermes display projection, tool identity, compression ancestry, working-directory, lifecycle and inference metadata without any live store or cache lookup. An explicit native ID is required for Hermes dumps and is never inferred from a database filename.

The native protocol neither creates backups nor publishes schedules. ccmsg captures whole SQLite databases using its online backup engine, validates and packages them, and retains their independent source identities. Snapshots are consistent per database, not globally atomic across profiles. Native databases preserve stored fields, but external attachment files, credentials, configuration and runtime state are outside this payload guarantee. Malformed conversation content may remain in a valid database and cause an explicit offline load error; raw capture validity must not require successful conversation reconstruction.
